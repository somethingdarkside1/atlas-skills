# Behavioral evidence gates a public skill release

Public source publication can carry a clearly marked unfinished plan, while a tagged skill release requires supported installation and independent behavioral evidence at the candidate revision. This preserves a useful public development process without presenting source availability as validated operation.

Considered: tagging the draft because manifests pass; delaying all public source until completion.
Revisit when: the supported release workflow or audience changes.

# The first public revision uses local task files

The proposed first public revision keeps canonical briefs and tasks in local files, with GitHub hosting and PR delivery controlled by the project. Hosted task tracking is deferred until a real need and adapter contract justify its pagination, identity, migration, and recovery cost.

Considered: native GitHub tracking in core; a generic tracker framework now; bidirectional mirroring.
Revisit when: a real adopter needs hosted task tracking and can exercise the same lifecycle tests.

# One interview skill covers both the foggy effort and the single part

Matt's set has `grill-with-docs` for an idea that fits one session and `wayfinder` for an effort too foggy to hold, storing the fog as decision tickets on a tracker. In Atlas the map already holds the fog: a sketched part is an open question. `/interview` takes a scope, the whole project or one part, and `/atlas` picks the next sketched part. The zoom lives in the map, so one skill is enough.

Open until the interview skill is written and piloted.

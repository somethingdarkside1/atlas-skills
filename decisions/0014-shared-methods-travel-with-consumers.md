# Shared methods travel with their consumers

Author each reasoning method once and generate versioned reference copies inside the installable skills that need it. This preserves selective installation while keeping one maintained definition and conditional loading; clean-profile tests determine the supported distribution paths.

Considered: assuming sibling skill installation; requiring the full bundle; publishing every method as a separate invoked skill.
Revisit when: a standalone method has a demonstrated independent use or distribution proves simpler with a full-bundle-only policy.

# Shared methods travel with their consumers

Author each reasoning method once and generate versioned reference copies inside the installable skills that need it. This keeps one maintained definition and conditional loading within the integrated product described by [0018](0018-one-method-modular-skills.md); clean-profile tests determine supported full-package and selective installation paths. Adopted on 2026-09-15 in [core-model/01](../plan/core-model/01-settle-boundaries.md); generation and installation support remain implementation work.

Considered: assuming sibling skill installation; requiring the full bundle; publishing every method as a separate invoked skill.
Revisit when: a standalone method has a demonstrated independent use or distribution proves simpler with a full-bundle-only policy.

# Each home carries its own format

**Part:** five-things

The format for each of the five things lives in a hidden comment at the top of the file (or a README in the folder), not in a separate reference skill. The agent always has the format in view while editing, the method travels with the project, and installing a single skill from skills.sh never leaves a dangling reference. Matt's set keeps formats in a model-invoked reference skill, which works only when the whole set is installed.

# Plain words over engineering jargon

Atlas is for anyone building something, so the names are the ones a non-programmer already knows: glossary not context, decision not ADR, brief not spec, task not ticket, part not module. An existing `CONTEXT.md` is adopted as the glossary so repos built on Matt's set keep working. The cost is that engineers lose a few familiar acronyms; the gain is a method one blog post can teach.

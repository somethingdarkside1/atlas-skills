# Atlas owns work and project instructions own delivery

Atlas operations create and assess work, shared methods supply reasoning, and project instructions govern commits, branches, worktrees, pushes, PRs, and merges. Acceptance concerns the named task outcome; integration is separately evidenced unless that outcome explicitly includes it, and existing authorization carries through to the project step. Adopted on 2026-09-15 in [core-model/01](../plan/core-model/01-settle-boundaries.md), this replaces [0007](0007-branches-only-with-github.md) for the revised release while the earlier executable draft awaits migration.

Considered: keeping Git inside each skill; centralizing Git in the Atlas plan format; removing all workflow awareness.
Revisit when: a concrete project action cannot be represented without changing Atlas acceptance semantics.

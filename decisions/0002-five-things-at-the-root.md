# The five things live at the project root

`GLOSSARY.md`, `MAP.md`, `plan/`, `decisions/`, and `notes/` sit at the root of every project, so a brand folder and a code repo look identical and a newcomer sees the whole method in one directory listing. Putting the folders under `docs/` would be quieter in a code repo but turns one rule into two.

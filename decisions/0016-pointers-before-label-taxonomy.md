# Context pointers precede a new label taxonomy

Use existing part ids and a small trigger-to-source index to choose relevant context, with explicit expansion through affected boundaries. Pointers locate authoritative homes and cannot override them; add labels only when measured retrieval improves enough to justify maintaining another classification. Adopted on 2026-09-15 in [core-model/01](../plan/core-model/01-settle-boundaries.md); no context-cost improvement is claimed before measurement.

Considered: reading every home on every turn; bucketed skill directories; a second status and label database.
Revisit when: cross-package retrieval repeatedly fails with the current pointers.

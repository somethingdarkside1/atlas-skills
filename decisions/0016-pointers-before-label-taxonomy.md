# Context pointers precede a new label taxonomy

Use existing part ids and a small trigger-to-source index to choose relevant context, with explicit expansion through affected boundaries. Add labels only when measured retrieval improves enough to justify maintaining another classification.

Considered: reading every home on every turn; bucketed skill directories; a second status and label database.
Revisit when: cross-package retrieval repeatedly fails with the current pointers.

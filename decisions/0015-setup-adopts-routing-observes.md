# Setup adopts the project and routing observes it

A separate setup-atlas operation adopts missing homes and an instruction pointer while preserving project-owned policy. Ordinary atlas inspection becomes read-only, and repairs or migrations have explicit scopes and receipts.

Considered: automatic mutation during every status check; silently recreating missing homes; inferring merge permission from authors.
Revisit when: real onboarding tests show the extra command is a larger burden than an equally explicit init mode.

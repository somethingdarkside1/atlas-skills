# 02: Verify GitHub approval and completion

## Delivers
A GitHub review and completion path that separates an Atlas report from platform approval, required checks, merge, and issue disposition.

Priority and source: P1; F09-F10, F23. See the [framework review](../../notes/2026-09-13-review-atlas-framework.md).

## Check by
Exercise author-equals-reviewer, failed checks, new PR commits, human merge, canceled issue, and merge failure in an isolated repository or fixture.

## Done when
- [ ] A same-account review produces a useful report without requiring author self-approval.
- [ ] A clean pass identifies the checked head and becomes stale after changes.
- [ ] Human merge waiting is durable and does not repeatedly approve or complete the task.
- [ ] Task completion follows verified integration and required checks, with canceled or manually closed work distinguished.
- [ ] Post-merge map and parent updates occur in a valid workspace and are recoverable.

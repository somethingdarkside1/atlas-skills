Its Git-in-plan policy and sibling-skill orchestration conflict with the newer direction and need reconciliation. It was not behaviorally tested. ## Deferred scope and reopening trigger

A hosted tracker adapter can be reconsidered when a real adopter needs it and the local lifecycle has passed its contract tests. Its work must cover stable identity, complete pagination, dependencies, evidence revisions, cancellation, recoverable writes, and explicit authority migration. A PR workflow alone is not a reason to add hosted task tracking.

Automatic cross-skill continuation can be reconsidered when supported invocation, bounded progress, durable human waiting, and failure recovery are demonstrated in a named harness. These deferred topics remain proposals rather than release blockers for the local, explicitly invoked first revision.

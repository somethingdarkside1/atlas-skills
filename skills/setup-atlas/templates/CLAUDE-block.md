## Atlas (atlas: 2)

This project uses Atlas. `GLOSSARY.md` holds the words, `MAP.md` the shape, `plan/` the work, `decisions/` the why, `notes/` the dated record. Read `GLOSSARY.md` and `MAP.md` before working and use their words. Each file starts with its own format; follow it. Write hard-to-reverse choices to `decisions/`. Run `/atlas` to see what is next. Atlas commands save their work the way `Saving work` below says.

## Saving work

When this folder is a git repo, each Atlas command commits the files it wrote, and only those, on the branch that is checked out, with the message that command names (for example `build wordmark/02: the lockups`). Nothing is pushed. When a hook rejects the commit, the command prints the hook's line and stops. This section belongs to the project: change it to match how work is saved and shared here, and the commands follow what it says.

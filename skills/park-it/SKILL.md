# Park it

Leave enough context for another session to resume without rediscovering settled work.

Read the current target, latest attempt or interview state, existing relevant handoff, note format, and workspace state. Current task and scope records remain authoritative.

1. Save newly settled facts in their proper homes first. Keep the task's partial output, observed checks, and pending action current under the plan working rules. Preserve unrelated work.
2. Write a dated handoff only for useful context not already recorded: a partially answered round, an unresolved investigation, or workspace details needed to find in-flight work. Identify the exact target and attempt/scope, relevant output version, workspace, and next action. Link existing records. If an adequate current handoff already exists and nothing changed, reuse it.
3. Save owned records under project policy. Report unsaved or externally pending work accurately. For a requested move to another workspace, tool, or person, export a portable copy with usable paths or URLs and the needed skill names, excluding secrets.

Finish with the direct resumption action or what it is waiting for. A future session checks this handoff against current scope, output, and answers; neither its date nor a matching status makes its directions authoritative.

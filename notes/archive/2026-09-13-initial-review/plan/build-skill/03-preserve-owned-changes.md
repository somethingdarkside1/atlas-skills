# 03: Preserve unrelated changes during commits

## Delivers
A shared owned-change commit procedure applied to build and other mutating skills, including map, glossary, decisions, and handoff updates.

Priority and source: P1; F08. See the [framework review](../../../../2026-09-13-review-atlas-framework.md).

## Check by
Begin with unrelated staged and unstaged edits, including one in a file the skill also edits; run a task and simulate a rejected commit hook.

## Done when
- [ ] The staged diff contains only the intended owned changes.
- [ ] All homes changed by the skill are accounted for in its receipt.
- [ ] Unrelated staged and unstaged edits retain their content and staging disposition.
- [ ] A rejected hook leaves an accurate task state and a concrete retry action.

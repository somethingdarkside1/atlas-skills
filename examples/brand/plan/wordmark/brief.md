# Wordmark

## Problem
The studio name is set in a default font on every surface, so nothing looks like it belongs to the studio.

## Outcome
One wordmark that reads as the studio's own at every size from a favicon to a shopfront sign.

## Decisions
[0001](../../decisions/0001-one-mark-not-a-family.md): one mark, not a family.

## Out of scope
A symbol or icon. Colour beyond ink and paper.
